Principais categorias do HTML5:

Metadata Content Flow Content Sectioning Content Heading Content Phrasing Content Embedded Content Interactive Content

Metadata Content

<title> Informa o titulo

<meta> Definir Codificação

<link> e <style> Importar CSS

<script> Configurar o comportamento da pagina (javascript)

Flow Content

Representa a maior parte dos elementos usados no body

<div> Caixa de divisão genérica, serve para agrupar "pedaços" de código

<p> Para colocar paragrafos na minha página.

<section> Agrupa conteúdos que partilham do mesmo assunto ou idéia.

<article> Conteúdo independente e completo por si só (faz sentido sozinho).

<img> Mostra uma imagem, foto, desenho, etc. (não precisa de tag de fechamento)

<form> Criar formulários, o usuário poderá digitar dados, enviar mensagem ou fazer login.

Sectioning Content

Organizar grandes áreas do documento

<Section> Agrupa conteúdos que partilham do mesmo assunto ou idéia.

<article> Conteúdo independente e completo por si só (faz sentido sozinho).

<Aside> Serve para guardar um conteúdo secundário/lateral (links relacionados, anúncios, biografia e etc).

<Nav> Agrupa links de navegação

Heading Content

h1, h2, h3, h4, h5 e h6 -> Para adiconar títulos e subtítulos

<hgroup> Serve para agrupar elementos de título, exemplo:

Aprenda HTML

Senai Americana

Phrasing Content

Elementos que marcam textos ou partes de texto

<span> Um bloco genérico, não muda nada sozinho. Serve para agrupar pedaços de texto e aplicar CSS ou funções com javascript.

<a> Cria um link para direcionar o usuário para outra pagina, utilizando o atributo href. Exemplo: Clique aqui para ir ao site do bitcoin

<strong> Deixar uma parte do texto em negrito

<em> Deixar uma parte do texto em itálico

<mark> Adciona um marcador em uma parte do texto

<img> Mostra uma imagem, foto, desenho, etc. (não precisa de tag de fechamento)
